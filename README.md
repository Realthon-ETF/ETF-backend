## 📌 서비스 소개

취업을 준비하는 대학생들은 채용 공고, 학교 공지, 프로그램, 대외활동 등 중요한 정보를 여러 웹사이트에서 직접 확인해야 합니다.

하지만

- 정보가 여러 사이트에 **파편화되어 있음**
- **알림 기능이 없는 웹페이지가 많음**
- 채용 공고는 **짧은 기간 내 마감되는 경우가 많음**

이러한 문제로 인해 많은 취준생들이 **중요한 기회를 놓치고 있습니다.**

**알려주잡**은 사용자의 **이력서를 기반으로 AI가 필요한 정보를 분석하고**, 사용자가 등록한 웹사이트에서 필요한 공지를 선별하여  
**카카오톡 알림으로 전달하는 서비스**입니다.

---

## 🚀 주요 기능

#### 1️⃣ AI 기반 정보 분석
사용자의 이력서와 관심분야 등을 분석하여 필요한 정보와 경험을 파악하고 맞춤형 정보를 추천합니다.

#### 2️⃣ 웹사이트 정보 수집
학교 공지 및 채용 사이트 등 사용자가 원하는 다양한 웹사이트에서 크롤링하여 취업 관련 정보를 수집합니다.

#### 3️⃣ 추천 데이터 선순환 구조
사용자들이 저장한 링크 데이터를 기반으로 추천 리스트가 지속적으로 확장되는 구조입니다.

#### 4️⃣ 카카오톡 알림
새로운 정보가 업데이트되면 매일 사용자가 원하는 시간에 카카오톡 알림을 통해 사용자에게 전달합니다.
